# Teradata Developer Guides

The Teradata Developer Guides help technical users  database administrators (DBAs), developers, data scientists, AI engineers, analysts, and technical users get started and succeed with Teradata products and integrations.

Each page in this resource is a standalone guide that covers topics such as accessing Teradata across different cloud service providers, data management, application development, and data analysis using tools like Power BI, SageMaker, Jupyter Notebooks, and more.
